# lxj_chat

The original reference page is preserved under `legacy/`. The former LXJ
launcher entry was an alias of `apps/chat` and has been removed. Chat owns the
active conversation UI, sessions, history, text input, and audio capture.

The reference page also called the old firmware's file-upload browser and
backend directly. Those calls were never part of the DeepStoa LXJ entry;
`apps/chat/service/chat_svc_mock.c` remains the active reply service.
